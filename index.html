How it works

  • Every chord, bass line and melody is stored as scale-degree numbers instead of fixed notes. Choosing a mode re-maps those numbers onto a new scale, so the whole arrangement changes mode at once, even mid-song.
  • Each style has a home mode chosen to match its mood. Lydian suits dreamy bedroom pop, Dorian suits late-night R&B, Locrian suits villain-movie trap. Then you can push any style somewhere it was never meant to go.
  • Write a new topline composes a fresh melody from a seed number. It builds a rhythmic motif, answers it, repeats it over the next chord and lands on a chord tone, using rhythm and register rules tuned to each style. The seed is saved in the page address, so you can share a melody you like.
  • Every sound is synthesized live with the Web Audio API: FM electric piano and bells, formant-filtered "vocal" leads, gliding 808s, and drums built from filtered noise and pitched sine waves.

About the styles

Each song is an original composition written for this project in the general production style associated with the artists named on its card: tempo, groove, instrument choices, chord colors and melodic habits.

No melodies, lyrics, samples or recordings from those artists are used, and this project is not affiliated with or endorsed by any of them. Artist names are used only to describe musical style.
